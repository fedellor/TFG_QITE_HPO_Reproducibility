\chapter{Manuales técnicos}

El código fuente íntegro desarrollado para este trabajo, así como los conjuntos de datos experimentales y los \textbf{scripts} de supercomputación, se encuentran disponibles de forma pública en el repositorio de GitHub: \url{https://github.com/fedellor/TFG_QITE_HPO_Reproducibility}.

\vspace{0.5cm}
Este repositorio ha sido diseñado bajo un paradigma de reproducibilidad estricta, conteniendo exclusivamente los archivos necesarios para ejecutar el \textbf{pipeline} algorítmico final y generar los resultados empíricos expuestos a lo largo de este documento.

\section{Estructura de ficheros}

A continuación, se detalla de forma exhaustiva la topología completa del repositorio, agrupada en carpetas funcionales:

\begin{itemize}
    \item \textbf{Directorio Raíz}:
    \begin{itemize}
        \item \texttt{README.md}: Documento de presentación, resumen del flujo metodológico y guía rápida de uso del repositorio.
        \item \texttt{tfg.pdf}: Archivo de la memoria académica oficial en formato PDF.
        \item \texttt{.gitignore}: Archivo de exclusión que filtra archivos temporales (como \texttt{\_\_pycache\_\_}), logs del clúster, entornos virtuales y metadatos de IDEs.
    \end{itemize}

    \item \textbf{Módulo de Código Fuente (\texttt{src/})}: Agrupa la lógica ejecutable del pipeline y los procesadores:
    \begin{itemize}
        \item \texttt{config.py}: Definición de hiperparámetros por defecto, nombres de marcas temporales, configuración de semillas pseudoaleatorias ($7, 42, 99, 123, 1001$) y rutas del clúster.
        \item \texttt{embeddings.py}: Implementación en PyTorch de la conversión de atributos del log de eventos a embeddings continuos unificados.
        \item \texttt{encoders\_and\_decoders.py}: Implementación de la arquitectura de red \texttt{EventTransformer} (bloques de autoatención multicabeza).
        \item \texttt{output\_layers.py}: Capas lineales finales de proyección para predecir de forma multiobjetivo la siguiente actividad, tiempo de ciclo restante y recursos.
        \item \texttt{training.py}: Rutina de entrenamiento por lotes, optimización AdamW, decaimiento del gradiente y control de funciones de pérdida.
        \item \texttt{evaluation.py}: Algoritmo evaluador que calcula la exactitud mediante la distancia de similitud de Damerau-Levenshtein en secuencias predictivas.
        \item \texttt{utils.py}: Funciones auxiliares de procesamiento de trazas, vectorización y padding.
        \item \texttt{sampler\_hpo.py}: Script de muestreo uniforme del espacio continuo-discreto con filtro de divisibilidad de hardware.
        \item \texttt{train\_hpo.py}: Script wrapper que gestiona el entrenamiento de 5 pliegues y persiste atómicamente los resultados con bloqueo de archivos (\texttt{fcntl}).
        \item \texttt{generate\_qubo.py}: Módulo de ajuste de regresión regularizada Lasso L1 LARS Cross-Validation para construir el QUBO.
        \item \texttt{solve\_bayes\_opt.py}: Solucionador clásico mediante procesos gaussianos.
        \item \texttt{solve\_vqe.py}: Solucionador cuántico variacional VQE empleando el simulador MPS o la QPU real.
        \item \texttt{solve\_qite.py}: Solucionador cuántico VarQITE resolviendo la ecuación de McLachlan con integrador de Euler de paso fijo.
        \item \texttt{generate\_plots.py}: Módulo encargado de compilar los CSV y renderizar las gráficas del TFG.
        \item \texttt{train.ipynb}: Cuaderno Jupyter de soporte rápido para entrenamientos manuales e interactivos.
        \item \texttt{README.md}: Documento explicativo de la estructura del módulo de código fuente y la función de sus componentes.
        \item \textbf{\texttt{data\_processors/}}: Carpeta que contiene la tubería de formateo y carga de logs:
        \begin{itemize}
            \item \texttt{attributes.py}: Extractor de tipos de atributos categóricos y numéricos.
            \item \texttt{event\_logs.py}: Cargador del log XES y mapeador de marcas de tiempo del proceso.
        \end{itemize}
    \end{itemize}

    \item \textbf{Gestión de Datos (\texttt{data/})}: Almacenamiento de logs de eventos, matrices y pesos neuronales:
    \begin{itemize}
        \item \texttt{resultados\_hpo.csv}: Historial maestro con el pool clásico de HPO y sus 300 experimentos base.
        \item \texttt{matriz\_qubo.csv}: Matriz binaria simétrica $Q$ (30x30) de acoplamiento cuántico.
        \item \texttt{metricas\_qubo.json}: Archivo que almacena la configuración del espacio, RMSE y el multiplicador de Lagrange $\lambda$.
        \item \texttt{README.md}: Documento descriptivo de los conjuntos de datos, modelos entrenados y trazas del proceso.
        \item \textbf{\texttt{models/}}: Carpeta que almacena los pesos preentrenados del predictor (\texttt{env\_permit\_fold0\_event\_predictor.pth}).
        \item \textbf{\texttt{event\_log/}}: Directorio con las trazas de minería de procesos:
        \begin{itemize}
            \item \texttt{attributes.yaml}: Definición semántica de actividades, recursos y tiempos.
            \item \texttt{env\_permit.xes.gz}: Registro de eventos original comprimido.
            \item \texttt{window\_sizes.json}: Configuración de tamaño de ventana para el EventTransformer.
            \item \textbf{\texttt{splitted/}}: Trazas divididas en 5 folds para validación cruzada, conteniendo los archivos en formato comprimido \texttt{train\_foldX\_env\_permit.xes.gz}, \texttt{val\_foldX\_env\_permit.xes.gz} y \texttt{test\_foldX\_env\_permit.xes.gz} (donde $X \in \{0, 1, 2, 3, 4\}$).
        \end{itemize}
    \end{itemize}

    \item \textbf{Resultados e Imágenes (\texttt{resultados/})}:
    \begin{itemize}
        \item \texttt{resultados\_soluciones\_reales.csv}: Base de datos unificada que consolida las 55 soluciones.
        \item \texttt{resultados\_bayes\_opt.csv}: Salida de la Optimización Bayesiana clásica (5 semillas).
        \item \texttt{resultados\_vqe\_sweep.csv} y \texttt{resultados\_qite\_sweep.csv}: Resultados de barrido de ruido en FT3.
        \item \texttt{resultados\_vqe\_qmio.csv} y \texttt{resultados\_qite\_qmio.csv}: Resultados físicos en la QPU de Qmio.
        \item \texttt{README.md}: Documento explicativo de las tablas de resultados y los gráficos generados.
        \item Gráficos de salida en alta resolución: \texttt{comparativa\_tiempos.png}, \texttt{comparativa\_energia.png}, \texttt{comparativa\_factibilidad.png}, \texttt{impacto\_ruido\_factibilidad.png}, \texttt{promedio\_violaciones.png}, \texttt{comparativa\_tiempos\_semillas.png}, \texttt{degradacion\_tiempo\_ruido.png}, \texttt{comparativa\_energia\_desglosada.png}, \texttt{frontera\_pareto.png} y \texttt{comparativa\_precision.png}.
    \end{itemize}

    \item \textbf{Orquestación HPC (\texttt{slurm/})}: Colección de scripts de envío a colas mediante Slurm:
    \begin{itemize}
        \item \texttt{setup\_env.sh}: Instalador automatizado del entorno virtual aislado con CUDA.
        \item \texttt{launch\_hpo.sh}: Script array de Slurm (tareas 1-100) para procesar el pool clásico HPO.
        \item \texttt{run\_bayes\_opt.sh}, \texttt{run\_vqe.sh}, \texttt{run\_qite.sh}: Envíos para resolvedores en la partición clásica.
        \item \texttt{run\_vqe\_qmio.sh}, \texttt{run\_qite\_qmio.sh}: Enrutadores para ejecutar VQE y VarQITE en Qmio.
        \item \texttt{README.md}: Documento explicativo de la configuración y orquestación de trabajos de supercomputación.
    \end{itemize}

    \item \textbf{Documentación (\texttt{docs/})}:
    \begin{itemize}
        \item \texttt{Formula QUBO.png}: Render gráfico del Hamiltoniano de Ising.
        \item \texttt{GrIA\_TFG\_Modelo\_A\_Memoria.pdf}: PDF con el borrador de la memoria.
        \item \texttt{QUBO\_MultiObjective\_Formulation.md}: Borrador markdown de la formulación multiobjetivo.
        \item \texttt{TFG\_Master\_Report_HPO.md}: Reporte maestro del proyecto.
        \item \texttt{resumen\_abstract.tex}: Archivo LaTeX del resumen de la tesis.
        \item \texttt{agradecimientos.tex}: Archivo LaTeX de los agradecimientos del trabajo.
        \item \texttt{manuales\_tecnicos.tex}: LaTeX del presente Apéndice A.
        \item \texttt{README.md}: Documento descriptivo de los informes, borradores y fuentes de documentación del proyecto.
    \end{itemize}
\end{itemize}

\section{Creación del entorno}

Para asegurar la estabilidad en la reproducción de los cálculos y evitar conflictos de dependencias, se distingue el uso de dos entornos de ejecución en el clúster: por un lado, se utiliza \textbf{Python 3.10.8} para la fase clásica de aprendizaje profundo y entrenamiento HPO masivo sobre las GPUs NVIDIA A100 del FinisTerrae III; por otro lado, se requiere estrictamente el uso de \textbf{Python 3.9.9} para la fase de resolución cuántica (tanto simulación como conexión directa a la QPU de Qmio) para garantizar la compatibilidad con el middleware de control cuántico \texttt{qmiotools}.

\vspace{0.5cm}
Las instrucciones para inicializar el entorno virtual desde una terminal en FT3 son:

\begin{enumerate}
    \item Clonar el repositorio y acceder a la carpeta:
    \begin{verbatim}
git clone https://github.com/fedellor/TFG_QITE_HPO_Reproducibility.git
cd TFG_QITE_HPO_Reproducibility
    \end{verbatim}
    
    \item Ejecutar el script de aprovisionamiento de dependencias y activación en la partición Store de FT3:
    \begin{verbatim}
chmod +x slurm/setup_env.sh
./slurm/setup_env.sh
    \end{verbatim}
\end{enumerate}

\section{Reproducción de los resultados}

El pipeline de experimentos híbrido se reproduce siguiendo un orden secuencial estructurado:

\begin{enumerate}
    \item \textbf{Generación del Pool HPO:} Ejecute el muestreo y envíe el array de trabajos a las GPUs A100 del FT3 para entrenar los 300 modelos Transformer base:
    \begin{verbatim}
python src/sampler_hpo.py
sbatch slurm/launch_hpo.sh
    \end{verbatim}
    
    \item \textbf{Ajuste del QUBO:} Una vez completados los entrenamientos clásicos, compile la superficie matemática cuadrática y obtenga la matriz QUBO:
    \begin{verbatim}
python src/generate_qubo.py
    \end{verbatim}
    
    \item \textbf{Ejecución de los Resolvedores (FT3 y Qmio):} Lance los resolvedores clásicos, simulaciones con ruido en FT3 o despliegues físicos en la QPU real de Qmio mediante los scripts de Slurm:
    \begin{verbatim}
sbatch slurm/run_bayes_opt.sh
sbatch slurm/run_vqe.sh
sbatch slurm/run_qite.sh
sbatch slurm/run_vqe_qmio.sh   # Para ejecutar VQE en la QPU de Qmio
sbatch slurm/run_qite_qmio.sh  # Para ejecutar VarQITE en la QPU de Qmio
    \end{verbatim}
    
    \item \textbf{Validación de Soluciones y Graficado:} Tras la finalización de los solucionadores, reentrene las soluciones óptimas inéditas en GPU y compile los diagramas de Pareto e histogramas ejecutando:
    \begin{verbatim}
python src/generate_plots.py
    \end{verbatim}
\end{enumerate}
